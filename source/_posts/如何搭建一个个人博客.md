## 前言
突发奇想，想搭建一个个人博客，要记录些什么也还没想好。
根据 AI 的推荐，选择了 Hexo 和 Github pages，因为它们免费。

## 准备工作
### 安装工具
安装 Node.js 和 Git。

### 创建 Github 仓库
创建一个 Github 仓库，用于存储博客代码。
命名为：你的用户名.github.io
可见性设为 Public

### 配置 SSH 密钥
为了推送代码时不用每次都输入账号密码，配置 SSH 密钥。
在本地终端执行以下命令：
``` bash
ssh-keygen -t rsa -C "你的GitHub注册邮箱"
```
连续按三次回车，使用默认设置。邮箱也只是为了方便识别，不是必须的。
我用的是 Windows 11，密钥对存储在 C:\Users\你的用户名\.ssh\id_rsa.pub。
复制密钥对内容，配置到 Github 仓库的 SSH 密钥中。

***

使用以下命令测试连接是否成功（有的网络会屏蔽 SSH 默认的 22 端口）：
``` bash
ssh -T git@github.com
ssh -T -p 443 git@ssh.github.com
```
看到 `hi 你的用户名!` 就说明配置成功。

## 搭建 Hexo 博客
### 安装 Hexo
``` bash
npm install -g hexo-cli
```
`-g` 表示全局安装。

### 初始化 Hexo
找一个存放博客项目的目录，在终端进入该目录，执行：
``` bash
hexo init blog
cd blog
npm install
```
这会生成一个完整的 Hexo 项目。

***
启动本地预览：
``` bash
hexo server
```
浏览器打开 `http://localhost:4000`，能看到 Hexo 默认页面就说明初始化成功。
按 `Ctrl+C` 停止服务器。

### 配置 Hexo
打开博客目录下的 `config.yml` 文件，修改以下内容：
``` yaml
url: https://你的用户名.github.io
```
这是为了生成的静态网页可以正确生成各种链接，比如：文章链接，图片链接。

## 部署到 Github pages，配置 Github Actions 自动部署
### 设置 Github Actions 工作流
在博客根目录下创建文件夹和文件：
```text
.github/workflows/pages.yml
```
这个文件可以让 AI 生成，例如：
``` yaml
name: Pages

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          token: ${{ secrets.GITHUB_TOKEN }}
          submodules: recursive

      - name: Use Node.js 22
        uses: actions/setup-node@v4
        with:
          node-version: "22"

      - name: Cache NPM dependencies
        uses: actions/cache@v4
        with:
          path: node_modules
          key: ${{ runner.OS }}-npm-cache

      - name: Install Dependencies
        run: npm install

      - name: Build
        run: npm run build

      - name: Upload Pages artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./public

  deploy:
    needs: build
    permissions:
      pages: write
      id-token: write
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```
这段配置的作用是：每次推送到 main 分支，GitHub 就会自动安装依赖、构建 Hexo、把生成的静态网页发布到 GitHub Pages。

### 推送
建 Git 仓库并推送到 Github 仓库。

### 开启 Github Pages
推送成功后，回到 GitHub 仓库页面：
1.进入 Settings；
2.左侧点击 Pages；
3.在 Build and deployment 下，把 Source 从 Deploy from a branch 改成 GitHub Actions。
然后点击顶部 Actions 标签，等待工作流变绿。

ok，就可以在浏览器打开 `https://你的用户名.github.io`，看到博客了。
